Portfolio Customization & Hosting Guide

How to replace links, add screenshots, and host for free

How to update your Itch.io Links and Game Data:

Open this index.html file in any text editor (like VS Code or Notepad). Look for the const GAMES_DATA = [...] JavaScript array near line 450. You can edit game titles, descriptions, itch.io URLs, and screenshot image links easily.

Adding Your Screenshots & Videos:

Replace the placeholder image URLs (e.g. from placehold.co) with your actual screenshot images. You can host images on Imgur, Discord, GitHub, or in the same folder. For the showreel video, replace the YouTube ID inside the <iframe> with your video's embed link.

Hosting on Google Drive or Free Web Hosts:

  • Google Drive: You can upload this HTML file to Google Drive and use tools like DriveToWeb (drv.tw) to turn a public Google Drive folder into a live website.
  • GitHub Pages: Push this file named index.html to a GitHub repository and turn on Pages in Settings for free, instant HTTPS hosting!
  • Netlify / Vercel: Drag and drop the folder containing this file to Netlify Drop for instantaneous hosting.
